## 📌 Project Overview

This project focuses on creating **SEO-optimized title tags, meta descriptions, and target keywords** for the PaperNest website.

The project was completed as part of a **Digital Marketing / SEO internship task with Veda Technology**. The goal is to improve how website pages are represented in search engine results and make the content more relevant, clear, and attractive to potential visitors.

The project covers five important website pages:

- Home
- Products
- Eco-Friendly Products
- Blog
- Contact Us

For each page, a primary target keyword, SEO title tag, meta description, search intent, and optimization explanation have been developed.

---

## 🎯 Project Objectives

The main objectives of this project are:

- Understand the fundamentals of On-Page SEO.
- Identify relevant target keywords for different website pages.
- Create unique and SEO-friendly title tags.
- Write clear and engaging meta descriptions.
- Match keywords with appropriate search intent.
- Avoid keyword stuffing and maintain natural language.
- Organize SEO research and recommendations in a structured format.
- Develop practical digital marketing skills.

---

## 🔍 What is On-Page SEO?

On-Page SEO refers to optimizing elements within a website so that search engines and users can better understand the content of each page.

Important elements considered in this project include:

- Target keywords
- Title tags
- Meta descriptions
- Search intent
- Content relevance
- User experience
- Keyword placement
